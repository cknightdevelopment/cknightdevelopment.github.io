# knightcodes.com

Personal developer blog. Jekyll 4 + Tailwind CSS v4, deployed to GitHub Pages (custom domain in `CNAME`) by `.github/workflows/pages.yml`.

**Pushing to `master` publishes the live site.** Never commit or push without being asked.

**Post content is Chris's own writing, never AI-generated.** Don't add, remove or reword anything in a post, typos included (point them out instead). Help only with formatting, wrapping existing passages in call-outs, and proposing a TL;DR for approval. Use the `new-post` skill when turning writing into a post.

## Commands

- `npm run dev`: serves http://localhost:4000 with live reload, drafts included, and Tailwind in watch mode.
- `npm run build`: production CSS + site build into `_site/`. Run it to verify changes before committing.
- `npm run check:links`: checks internal links in `_site/` (run after a build). Deploys run this too; `.github/workflows/links.yml` checks external links weekly.

Ruby comes from Homebrew (`/opt/homebrew/opt/ruby/bin`); macOS system Ruby is too old.

## Layout

- `_posts/YYYY-MM-DD-slug.md`: published posts. `_drafts/slug.md`: unpublished, shown only in `npm run dev`.
- `_drafts/example-post.md`: reference for every post feature. Keep it current when adding features.
- `_layouts/`, `_includes/`: HTML templates styled with Tailwind utility classes.
- `_css/main.css`: Tailwind entry point and custom styles, compiled to `assets/css/main.css` (git-ignored, never edit it).
- `_css/syntax.css`: generated by `bundle exec rougify style github.dark`. Don't hand-edit.
- `_plugins/callouts.rb`: turns `> [!NOTE]`-style blockquotes into call-outs.
- `_plugins/headings.rb`: `#` anchor links on h2-h4, and the table of contents for `toc: true`.
- `_plugins/post_data.rb`: related posts by shared tags; copies `updated` to `last_modified_at` for the SEO/sitemap plugins.
- `_plugins/tag_colors.rb`: `tag_color` filter that gives each tag a stable color (`.tag-<color>` in `_css/main.css`). Pin a tag's color in `_data/tag_colors.yml`.
- `assets/js/main.js`: dark mode toggle, code copy buttons, home page tag filter and search.
- `search.json`: search index generated at build time.
- `assets/images/posts/<slug>/`: images for a post.

## Post format

```markdown
---
layout: post
title: Title
date: 2026-10-25 14:30 -0500   # time optional; shown when set
tags: [javascript, css]        # lowercase, reuse existing tags
tldr: One or two sentences.    # optional, markdown allowed
updated: 2026-11-02            # optional, when a post is revised
toc: true                      # optional, for long posts
---
```

Call-outs: `> [!NOTE]`, `[!TIP]`, `[!IMPORTANT]`, `[!WARNING]`, `[!CAUTION]`, optionally followed by a custom title on the same line. Code blocks: fenced, always with a language.

## Styling

Keep it simple and minimal. Colors: `primary-*` (emerald, defined in `@theme inline` in `_css/main.css`) for links, accents and active states; `zinc-*` for neutrals. Never use raw `emerald-*` or `gray-*` in templates. Site-chrome links use the `.link` class; links inside `.prose` are styled automatically. Animations are short (≤350ms) and wrapped in `motion-safe:`, so they respect reduced-motion settings.

## Gotchas

- Dark mode is class-based (`.dark` on `<html>`, set by an inline script in `default.html` and toggled in `main.js`), not media-query based. `dark:` utilities still work as normal.

- Custom CSS in `_css/main.css` is deliberately outside `@layer components`, so it beats the typography plugin's `.prose` styles. Keep it that way.
- Changes to `_config.yml` or `_plugins/` need the dev server restarted.
- The Tailwind watcher must use `--watch=always`; plain `--watch` exits when backgrounded.
